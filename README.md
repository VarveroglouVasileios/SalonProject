# Kalypso Studio · demo concept

Demo για επιδείξεις σε πελάτες: φανταστικό studio περιποίησης με **online ραντεβού ανά υπηρεσία και ειδικό**. Δεν είναι πραγματική επιχείρηση και τα ραντεβού δεν στέλνονται πουθενά.

Live: https://varveroglouvasileios.github.io/SalonProject/

## Τι δείχνει
- Επιλογή υπηρεσίας → ειδικού (ή «όποιος είναι διαθέσιμος») → ημέρας → ώρας.
- Οι ελεύθερες ώρες υπολογίζονται από **τη διάρκεια της υπηρεσίας**, το ωράριο του ειδικού (ημέρες, Σάββατο, διάλειμμα), 10 λεπτά καθαρισμού μετά από κάθε ραντεβού και 1 ώρα προειδοποίηση για σήμερα. Ραντεβού δεν μπορούν να επικαλυφθούν.
- Με «όποιος είναι διαθέσιμος» ο ειδικός ορίζεται από τη λιγότερο φορτωμένη ημέρα. Ο έλεγχος επαναλαμβάνεται κατά την επιβεβαίωση.
- Ημερολόγιο προσωπικού (`#/staff`, κωδικός `demo`): ραντεβού ανά ειδικό και ώρα, ολοκλήρωση, ακύρωση.

## Τεχνολογία
Vue 3, TypeScript, Tailwind, vue-router (hash history για GitHub Pages), Vitest. Η λογική (ωράρια, επικαλύψεις, buffer, ανάθεση) είναι καθαρές συναρτήσεις στο `src/lib/schedule.ts` με tests. Τα δεδομένα μένουν στο `localStorage` και το ημερολόγιο έχει «Επαναφορά demo».

```bash
yarn install
yarn dev     # τοπικά
yarn test    # tests λογικής
yarn build   # production build
```

Οι φωτογραφίες είναι δημιουργημένες με AI και ενδεικτικές. Σχεδιασμός και υλοποίηση: Βασίλειος Βαρβέρογλου.
